# marked

Markdown → HTML az útmutató oldalához (`help/index.html`): a `docs/` mappa Markdown-fájljait a böngészőben alakítja
át, így az útmutató egyetlen forrása a `docs/` marad.

- Változat: marked 18.0.14 (<https://github.com/markedjs/marked>), MIT licenc (`LICENSE`).
- Fájl: `marked.umd.js` (a csomag `lib/marked.umd.js`-e, változtatás nélkül).
- Frissítés: `npm pack marked@<változat>`, a `lib/marked.umd.js` és a `LICENSE` ide másolása, majd a változatszám
  javítása ebben a fájlban.
